# 视觉方法

| ID | 方法 | 必要输入与画面目标 | 检查重点 |
| --- | --- | --- | --- |
| VG-01 | 主体揭示与收尾 | 正确商品图；迅速建立商品识别，结尾留足阅读时间 | SKU、轮廓、商品数量、CTA 可读性 |
| VG-02 | 材质与细节 | 清晰细节图；用光线和景别呈现表面 | 不凭光泽或水滴推断材质等级、防水等性能 |
| VG-03 | 使用与因果 | 真实操作步骤；连续展示操作与可见结果 | 接触关系、动作顺序、结果范围 |
| VG-04 | 简单结构变化 | 开合或组装参考；看清结构和操作 | 铰链、瓶盖、卡扣的位置与运动方向 |
| VG-05 | 空间连续 | 主体和场景位置；遮挡前后保持一致 | 左右关系、背景、光照和物体尺度 |
| VG-06 | 人物与产品交互 | 获准形象与操作参考；说明如何使用 | 手部接触、商品尺寸、表情与动作一致 |
| VG-07 | 动作与声音节奏 | 动作节点、口播和声音需求；形成清晰节拍 | 音画同步、音乐不遮盖关键信息 |
| VG-08 | 品牌与文字合成 | 正确 Logo 和文案、渠道安全区；保证辨识 | 拼写、价格、字幕、裁切与遮挡 |

参考素材各自承担明确职责：商品外观、场景、构图、动作、声音。相互冲突时先明确优先级，不能要求模型自行融合不同 SKU 或互斥动作。

首帧检查主体、数量、比例、产品结构和文案留白；末帧检查商品识别与 CTA 阅读时间。时间与安全区按照实际渠道要求确认，不固定套用一份像素值。

复杂动作失败时，先减少同镜任务、调整视角或拆镜；商品结构持续失真时采用真实素材或确定性制作。装饰特效应作为视觉表达，不能承担真实功效证明。
