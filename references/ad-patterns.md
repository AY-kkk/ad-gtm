# 广告结构

根据传播目标和已有证据选择结构。表中测试变量是实验候选，不代表已验证效果。

| ID | 结构 | 信息顺序 | 必需输入 | 可测试变量 |
| --- | --- | --- | --- | --- |
| PAD-01 | 产品主视觉 | 亮相 → 设计细节 → 场景 → 收尾 | 正确产品图与 SKU | 开头构图、细节顺序 |
| PAD-02 | 问题与解决 | 日常问题 → 使用 → 可见结果 → CTA | 问题与功能的事实依据 | 问题开头 |
| PAD-03 | 使用演示 | 初始状态 → 操作 → 结果 → 下一步 | 真实步骤或演示素材 | 景别、演示顺序 |
| PAD-04 | 单一利益 | 一个利益 → 证据 → 情境 → CTA | 一项有来源的主张 | 利益表述、证据呈现 |
| PAD-05 | 生活场景 | 情境 → 产品出现 → 使用 → 收尾 | 商品在场景中的实际用途 | 场景、进入方式 |
| PAD-06 | 顾虑解释 | 用户顾虑 → 事实 → 回答 → CTA | 顾虑来源与答案证据 | 开头问句 |
| PAD-07 | 功能解释 | 使用问题 → 机制说明 → 可见效果 | 有依据的机制和示意范围 | 演示或图解 |
| PAD-08 | 创作者风格演示 | 自然开场 → 演示 → 核心信息 → CTA | 演示稿、形象与声音授权 | 语气、演示视角 |
| PAD-09 | 优惠活动 | 活动信息 → 商品价值 → 条件 → CTA | 有效价格、期限与适用条件 | 信息顺序 |
| PAD-10 | 同条件比较 | 比较问题 → 同条件证据 → 结论范围 | 真实可比数据及素材 | 比较维度 |
| PAD-11 | 品牌故事 | 情境 → 品牌角色 → 产品关联 → 记忆点 | 品牌事实与获准表达 | 故事角度 |
| PAD-12 | 已有素材改版 | 固定主体 → 修改指定部分 → 重验 | 素材权利、原版本与修改范围 | 开头、语言或结尾 |

PAD-07 的图解应明确其说明性质。PAD-08 的演员或虚拟角色不能冒充真实顾客证言。PAD-10 不用生成画面伪造竞品测试。PAD-12 涉及翻译时重新检查承诺、优惠条件与口播时长。

## 结构应用卡

```text
结构 ID：
受众与传播目标：
一个核心信息：
主张 ID 与来源：
叙事节点及其信息任务：
CTA：
选用的视觉方法：
待测试变量及固定项：
事实或素材缺口：
```

时长由广告目标和信息量决定，制作时再按实际模型限制拆段。不能为了填满模板而增加无关剧情。
