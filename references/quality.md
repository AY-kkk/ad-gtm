# 质量与实验

## 分阶段验收

| 阶段 | 检查内容 | 通过依据 |
| --- | --- | --- |
| 文案与制作计划 | 主张来源、素材权利、时间轴、素材映射、CTA | 来源记录与可执行分镜 |
| 生成片段 | SKU、数量、结构、动作、时序、画面与声音 | 实际视频及问题时间码 |
| 后期成片 | 文字、价格、Logo、口播、转场与阅读时间 | 完整成片复核 |
| 渠道交付 | 当前广告位的尺寸、时长、格式、安全区及必要标识 | 渠道要求及导出文件 |
| 媒体实验 | 指标、样本、归因窗口、成本与测试变量 | 投放数据及分析记录 |

每项记录 `not_run / pass / fail`、依据、检查人或工具和时间。没有视频只能检查计划，不能给成片打通过。商品错误、无依据主张、未获准素材及错误价格不能靠美观评分抵消。

失败记录包含：素材 ID、问题时间码、现象、可能原因、下一次只改变什么。复测所有受影响内容，保留失败尝试。

## 素材实验

测试前写清假设、变体与固定项、主要指标、基线、样本或预算、周期、归因窗口、停止规则。曝光、点击、转化等事件以实际渠道定义为准；没有基线时先做探索，不事后挑选最有利指标。

尽量保持受众、广告位、出价、时段和归因条件可比。记录流量分配与平台自动优化；比较受混杂因素影响时将结果标为观察性证据。样本不足时报告“不足以判断”，不把领先数值直接写成赢家。

将创意 ID、变体 ID、成片 ID、广告 ID 与实验 ID 关联。只需要其中某阶段时不强制填全套 ID。

## 制作成本

```text
制作总成本 = 实际生成账单 + 人工成本 + 素材与授权成本 + 后期成本
每条合格成片成本 = 制作总成本 / 验收通过的成片数
```

包含废片、重试与修改的实际消耗，统一币种和人工计价方法。没有合格成片时单条成本记为不可计算，同时报告已发生总成本。投放费用单列，不混入生成成本。

比较现有流程和模型流程时保持成片规格、验收标准与交付范围一致，分别报告制作周期和人工工时。价格来自当前报价或账单；预测值明确标为估算。
