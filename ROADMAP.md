# Roadmap

The next releases should improve evidence and repeatability in this order:

1. Add an optional local media-inspection command that records duration, frame size, codecs, audio presence, and sampled-frame notes without uploading media.
2. Add reusable platform briefs for short-video feeds, app stores, and landing pages, with placement-specific safe areas and CTA limits.
3. Add a small, permissioned benchmark set that reports creative quality, human edit time, and accepted-output cost separately.
4. Add provider adapters only when a public endpoint, model ID, account scope, and cost source can be cited and rechecked.
