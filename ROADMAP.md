# Roadmap

The next releases should improve evidence and repeatability in this order. Items remain planned until their implementation and tests are complete.

1. Build and test a complete local media inspector with decoded-frame, OCR, and ASR adapters before adding it to the public package.
2. Add reusable platform briefs for app stores and landing pages, with placement-specific safe areas and CTA limits.
3. Add a small, permissioned measured benchmark set that reports creative quality, human edit time, and accepted-output cost separately.
4. Add provider adapters only when a public endpoint, model ID, account scope, and cost source can be cited and rechecked.
