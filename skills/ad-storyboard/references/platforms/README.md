# Platform briefs

These are planning templates, not permanent platform specifications. Before export or launch, fill the current placement, duration, safe-area, caption, audio, CTA, and policy fields from the platform's official documentation. Record `checked_at` and the source URL in the production package.

| Template | Best starting use | First decision |
| --- | --- | --- |
| [Douyin](douyin.md) | 快速问题、演示、直播切片 | 第一秒是否能独立理解 |
| [TikTok](tiktok.md) | UGC、产品演示、趋势原生创意 | 静音观看是否仍然清楚 |
| [YouTube Shorts](youtube-shorts.md) | 结果先行、循环观看、搜索承接 | 结果和品牌是否在短时长内闭环 |
| [Instagram Reels](instagram-reels.md) | 视觉叙事、创作者合作、商品展示 | Feed 与 Story 裁切是否都可用 |

Do not treat a platform template as a performance guarantee. Use `ad-experiment` to compare variants under the same audience and placement.
