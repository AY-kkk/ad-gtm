# 广告创意与脚本

## 输入

已确认的受众、核心信息、主张来源、素材、CTA 与时长；可来自用户材料或 `ad-brief`，不要求安装上游 Skill。

## 方法

1. 用一句话写明“观众看完理解什么、做什么”。先确定传播任务，再选风格。
2. 按[广告结构](references/ad-patterns.md)筛选符合证据和素材条件的表达方式；不强制选多个模板。没有适配结构时直接设计。
3. 根据用户需求给出少量有实质差异的方向，每个说明受众切入点、核心承诺、证据怎样出现与制作难点。
4. 完成所选方向的开头、正文、收尾和 CTA。将画面、口播、字幕分开，准确价格和品牌文案注明后期合成。
5. 制作变体时写清改变项与固定项。只比较开头时，固定正文、商品信息与 CTA；多处变化时不能归因于单一因素。
6. 检查口播长度是否容纳于时长；文案中每项产品主张对应来源，无来源的证言、数字和承诺删除或标为待确认。

## 输出

每个方案包含 `concept_id`、受众切入点、核心信息、结构 ID、脚本、关联 `claim_id`、CTA、素材需求、制作风险和测试变量。创意优先级说明依据，不虚构“爆款率”或预计 ROAS。

## 完成标准与交接

观众利益明确，证据在脚本中有呈现位置，商品与 CTA 可辨，变体差异可描述。后续可交给 `ad-storyboard` 编排镜头；已有视频只改文案时直接输出修改稿。

## 示例

同一收纳盒可比较“寻找物品的日常情境”和“分格后的清晰桌面”两个开头；不为了戏剧性增加未证实的承重或防水功能。
