# Seedance 2.0 广告制作

## 输入

分镜或明确的单镜任务、正确产品素材、需要的声音、成片规格与已获准主张。可独立处理用户任务，无需安装其他 Skill。

## 方法

1. 读取[2.0 制作指南](references/production.md)，按短段和可替换镜头组织任务。
2. 记录 `provider / service / region / model_id / mode / checked_at`。查实际入口官方资料，确认时长、分辨率、输入格式和引用语法；用户账号权限另记 `unknown / available / unavailable`。
3. 建立内部素材 ID → 上传顺序 → 服务引用标记的映射。检查素材权利以及该入口对真人形象、声音的要求。
4. 生成任务逐项给出用途、起止状态、动作、运镜、声音、产品保留项及后期内容。超出单次限制时拆段，保留镜间连接条件。
5. 有工具和授权时，在费用上限与尝试次数内执行；记录任务 ID、参数、提示词版本、失败和账单。缺工具则交付制作包，执行标为 `not_run`。
6. 检查实际片段；结构失真先简化动作、调整视角或强化参考，仍失败则用实拍或确定性制作。不要无上限重试。

## 输出

运行配置、任务列表、逐任务提示词、素材映射、后期计划，以及实际执行时才有的结果位置与消耗。必须区分“提示词已准备”“已生成”“已验收”。

## 文档基线

2026-09-16 核验的 [BytePlus LAS](https://docs.byteplus.com/en/docs/Byteplus_LAS/video_gen_enhanced) 在 `ap-southeast-1` 列出 `dreamina-seedance-2-0-260128`，单次 4–15 秒；参考图片场景不支持 1080p。此服务包含前后处理，不能外推为其他入口或原生模型的参数，执行时重新核对。

## 完成标准与交接

所有任务符合当前服务限制，素材映射无歧义，未知权限明确可见。成片可交给 `ad-review`；本模块自身也要报告商品、动作与声音的明显错误。2.0 的编辑或延长能力按实际模式核验，不能默认只有从零生成。
