# Seedance 2.5 广告制作

## 输入

分镜或明确的镜头任务、产品素材、声音需求、成片规格与已获准主张。可独立处理任务，无需安装其他 Skill。

## 方法

1. 读取[2.5 制作指南](references/production.md)，判断连续演示是否有助理解。复杂动作或独立实验变量仍可拆段。
2. 记录 `provider / service / region / model_id / mode / checked_at`，核验当前入口的时长、分辨率、输入和编辑方式。账号权限另记 `unknown / available / unavailable`。
3. 将参考素材按商品、角色、场景、动作、声音分工；检查授权及服务的形象输入要求。记录内部 ID 与服务引用的映射，删除无职责或互相冲突的素材。
4. 按关键时间节点编写起点、操作、结果及保留项。长片段不只堆积运镜；准确文字、Logo、价格和 CTA 可后期合成。
5. 编辑任务明确源片段、目标范围、修改内容、保留区域及声音策略。提示词中的时间描述不能冒充确定性剪辑能力。
6. 在实际工具、授权、费用和尝试上限范围内执行并记录；无工具只交付制作包。失败先定位问题，达到上限停止或调整制作方法。
7. 完整观看片段，检查各节点、转场、商品和角色一致性；局部修改后复查整段。只抽几帧不等于完整验收。

## 输出

运行配置、参考分工、任务与提示词、连续性约束、后期及失败处理。实际结果、任务 ID 和账单仅在执行后报告，其他状态为 `not_run`。

## 文档基线

2026-09-16 核验的 [BytePlus LAS](https://docs.byteplus.com/en/docs/Byteplus_LAS/video_gen_enhanced) 在 `ap-southeast-1` 列出 `dreamina-seedance-2-5-260628`，单次 4–30 秒、输出 480p 或 720p。此服务包含前后处理，不能外推为其他入口或原生模型参数，执行时重新核对。

## 完成标准与交接

当前入口能力与账号状态分开记录，长段有清晰信息节点，修改范围与保留项明确。结果可交给 `ad-review`。与其他版本比较时保持同 brief、交付规格和验收标准，使用实际合格率与完整成本。
