# Seedance 2.5 制作指南

先完成[当前服务核验](../SKILL.md)。以下是制作建议，具体参数由实际服务决定。

## 镜头组织

- 当连续性直接帮助观众理解时，可将“使用前状态 → 操作 → 结果”放在较长单段中；可生成更长片段不代表每条广告都应加长。
- 将参考素材按商品、角色、场景、动作和声音分组。只加入承担明确职责的素材，避免多个商品版本或不同人物互相干扰。
- 长段按关键时间节点描述信息任务，保留商品外观与空间关系；复杂场景、不同 SKU 或独立测试变量仍适合分段。

## 示例：连续演示

```text
保留产品参考图中的外观与结构，操作顺序遵循使用参考。
开头让观众看清商品与桌面状态；中段连续完成一个真实操作；
结束时以同一视角展示操作后的状态，商品始终清晰可辨。
每个阶段只呈现一个信息重点，动作间有自然停顿。
声音与操作同步，准确文字和 CTA 使用后期合成。
```

根据脚本填入具体起止秒和实际引用。超过当前入口支持范围时拆段，不只更换模型名称后重试。

## 编辑与验收

编辑请求明确源片段、目标时间范围、要改变的内容、保留区域以及声音是否同步修改。先核验服务是否支持所需编辑方式；提示词中的时间描述不等同于精确剪辑工具。

长段验收至少覆盖开头、操作节点、转场和结束状态，并完整观看音视频，检查商品漂移、角色变化和口播遗漏。局部修改后复查整段；反复失败时拆镜或使用剪辑工具。

比较 2.0 与 2.5 时保持验收与成本口径一致，记录实际合格率、制作耗时和成本变化；需要完整对照试点时可使用 `ad-poc`。
