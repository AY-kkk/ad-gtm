# 商业方案与扩量

## 输入

试点结果、客户目标、当前成本和产量、报价依据、交付资源及采购要求。尚未试点时可起草方案框架，结果和收益保持待验证。

## 方法

1. 对照试点目标确认哪些场景通过、哪些失败、哪些证据不足。只把通过范围纳入生产建议，复杂新场景另设验证。
2. 写出价值主张与目标购买者，解释改善的是成本、速度、迭代范围还是质量。收益模型列出采用率、产量、人工计价、接入成本和敏感性，不把预测写成已实现收入。
3. 明确商业范围：交付物、频率、账号和素材责任、集成方式、计费依据、验收、修改次数与支持。报价引用当前来源或客户约定，不代厂商承诺价格、配额、SLA 或效果。
4. 按试点、付费试点、采购、生产接入、稳定复用分别记录证据。样片获赞不等于采购或上线。
5. 分批扩展相邻 SKU、渠道、语言或团队；每批设质量与成本阈值、负责人、复查日期、暂停条件和回退流程。
6. 将失败记录反馈给产品或解决方案团队：完整模型配置、输入版本、时间码、重现条件与业务影响。未经授权不发送客户资料或对外发布案例。

## 输出

一页商业方案、假设明确的收益测算、采购与落地里程碑、扩量检查表。每个动作指定负责人、依赖、完成证据和下一步。

## 完成标准

商业承诺有依据，尚未确认的采购事项可见，扩量范围与试点证据一致。对外案例仅使用获准资料并注明样本、时间和口径，不将制作质量提升表述为广告转化提升。

## 示例

三个 SKU 的产品亮相片通过 → 可先扩展相近 SKU；人物口播和复杂机械演示需要新的验证，不能一并宣称适用。
