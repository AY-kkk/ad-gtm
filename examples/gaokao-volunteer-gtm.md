# 高考志愿填报：创意展示案例

这是一条由案例提供方提交的产品 GTM 样片。它用于展示“问题—产品界面—结果—行动”的视频表达路径，不代表已经完成投放或证明了产品效果。

## 公共素材

- 视频：[`gaokao-volunteer-gtm.mp4`](https://github.com/AY-kkk/ad-gtm/releases/download/v0.3.0/gaokao-volunteer-gtm.mp4)
- 形式：约 15.07 秒，9:16 竖屏，720×1280，H.264 视频与 AAC 音频，文件约 8.0 MB。
- 素材状态：片中保留 `AI生成` 水印；二维码、品牌名、口播与产品授权需由发布方在投放前复核。

## 画面拆解

| 时间 | 观察到的内容 | GTM 作用 |
| --- | --- | --- |
| 0–4 秒 | 学习压力、书桌与焦虑情绪 | 让目标用户识别问题 |
| 4–8 秒 | 手机展示“智愿AI报考”及输入界面 | 说明产品入口与使用动作 |
| 8–10 秒 | “冲刺 / 稳妥 / 保底”等结果卡片 | 把功能转成可理解的输出 |
| 10–13 秒 | 用户走入校园或明亮环境 | 给出使用后的情绪结果 |
| 13–15 秒 | 品牌名、口号与二维码收尾 | 提供行动入口 |

## 验收结论

| 检查范围 | 状态 | 说明 |
| --- | --- | --- |
| 叙事与时长 | `pass` | 竖屏短片完成了问题、产品、结果和 CTA 的基本闭环 |
| 产品界面可辨 | `pass` | 产品名与志愿分层结果在关键帧可读 |
| 音频存在 | `observed` | 文件含 AAC 音轨；本案例页不把它当作已完成的口播逐字核验 |
| 生成模型与参数 | `not_run` | 未提供可复现的模型、版本、提示词、种子或生成日志 |
| 投放效果 | `not_run` | 没有曝光、点击、转化、成本、受众或渠道数据 |
| 权利与合规 | `not_run` | 需由素材和产品权利人确认品牌、二维码、学校场景与广告表述 |

## 可以学习什么

- 开头先呈现高考志愿选择的压力，降低解释成本。
- 手机界面承担产品证明，结果卡片把复杂服务压缩成三个决策词。
- 最后的校园场景完成情绪转场，但应补充真实产品准确性、适用范围和风险提示。

## 使用边界

本案例可作为**创意制作与产品表达案例**收录；不能写成“转化成功案例”“模型能力证明”或“志愿推荐准确率证明”。公开复用前，先替换为获得授权的品牌与二维码，重新检查小屏可读性、音画同步、口播逐字稿和教育类广告合规要求。
